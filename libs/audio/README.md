# Emulação de Áudio / APU MCPX (libs/audio)

*(Subsistema planejado para marcos futuros)*

## Responsabilidade
Emular os processadores de áudio do MCPX: o processador DSP de efeitos e o sintetizador de voz/canais de áudio 3D (EP/VP).

## Fronteiras e Dependências
- **Dependências permitidas**: `libs/common`, `libs/memory`, `libs/platform`.
